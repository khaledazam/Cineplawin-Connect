# دليل الهوية البصرية ونظام التصميم: واصل (Wassel)

> **"صوتك واصل.. وبلاغك محلول"**  
> الهوية البصرية، نظام الألوان، ونمط الواجهات لمنظومة البلاغات والمتابعة المدنية على واتساب ولوحة التحكم الإدارية.

---

## 1. فلسفة الهوية وقصة البراند (Brand Narrative)

### 1.1 الدلالة اللغوية والرمزية
* **الاسم العربي:** **واصل** (اسم فاعل من "وصل" و"تواصل").
  * يعني للمواطن: صوته وبلاغه *وصل* للمسؤولين دون وسيط، ورسالة الأمان بأن مشكلته في أيدٍ أمينة.
  * يعني للمؤسسة/المجلس: أداة *الوصل* الرقمية المباشرة مع الشارع وسرعة إنجاز الخدمات.
* **الاسم اللاتيني:** **Wassel** (سلس في النطق والبحث، مناسب لنطاق عالمي وإقليمي).
* **السلوجان الرسمي (Tagline):**
  * للمواطنين (B2C): **"صوتك واصل.. وبلاغك محلول"**
  * للجهات والمؤسسات (B2B/B2G): **"حلقة الوصل الذكية بين مدينتك ومواطنيك"**

### 1.2 نبرة الصوت وشخصية البراند (Brand Archetype & Tone of Voice)
* **الشخصية:** مزيج متناغم بين **الراعي الموثوق (The Caregiver)** و **المنجز السريع (The Everyday Hero)**.
* **النبرة مع المواطن (واتساب):**
  * لهجة عامية مصرية راقية ومهذبة، مباشرة، ودودة، وخالية من البيروقراطية أو التعالي ("تمام"، "ابعتلنا"، "اطمن").
* **النبرة مع الموظف والمسؤول (لوحة التحكم):**
  * عربية فصحى عصرية، دقيقة، مبسطة، وموجهة للبيانات والإنتاجية ("بلاغات جديدة"، "زمن الحل"، "تعيين موظف").

## 2. الشعار والرمز البصري (Logo & Symbol Anatomy)

### فكرة الشعار (The Concept)
يدمج الشعار بين ثلاثة عناصر جوهرية في رمز واحد متصل:
1. **حرف الواو العربي (و)**: الحرف الافتتاحي للعلامة، مرسوم بانسيابية هندسية تعبر عن الاستمرارية.
2. **دبوس الموقع الجغرافي (Location Pin)**: يعبر عن تحديد مكان المشكلة في الشارع والمدينة (Geo-location).
3. **عقدة الاتصال والشبكة (Connectivity Node)**: النقطة العلوية في الواو تتصل بمسار يعبر عن المراسلة اللحظية وشبكة الواتساب.

```
       [  عقدة الاتصال والبيانات  ]
                  ●
                 / 
               ╭──╮
              │  ● │  <--- حلقة حرف الواو (عين الاتصال)
               ╰──╯
                 \
                  ▼   <--- رأس دبوس الموقع الجغرافي
```

## 3. نظام الألوان (Color Palette & Tokens)

تم اختيار لوحة ألوان مستوحاة من **أصالة دلتا النيل والمدن المصرية** ممزوجة بـ **عصرية البرمجيات السحابية العالمية**؛ للابتعاد عن الألوان المستهلكة (الأزرق الباهت أو الأخضر التقليدي).

### 3.1 الألوان الأساسية (Core Brand Palette)

| اللون | اسم التوكن | Hex | HSL | الدلالة والاستخدام |
|---|---|---|---|---|
| **Deep Nile Teal** | `teal-900` | `#083344` | `197° 71% 15%` | اللون السيادي، يعبر عن الرصانة والمصداقية (الهيدر، القوائم الجانبية). |
| **Emerald Connection** | `primary-600` | `#0D9488` | `175° 84% 32%` | اللون التفاعلي الرئيسي، يربط بين لون الواتساب والثقة الرسمية (الأزرار الأساسية، الروابط النشطة). |
| **Soft Mint** | `primary-100` | `#CCFBF1` | `167° 85% 89%` | خلفيات التمييز الخفيفة والبادجات المهدئة. |
| **Warm Egyptian Amber** | `accent-500` | `#F59E0B` | `38° 92% 50%` | لون الحيوية والتنبيه الودود (البلاغات قيد المراجعة، علامات التحذير). |

### 3.2 الألوان الوظيفية لحالات البلاغات (Semantic Status Palette)

تتميز بتناسق هرمي مريح للعين أثناء فحص مئات الصفوف في لوحة التحكم:

| الحالة (Status) | التسمية العربية | لون الخلفية (Badge BG) | لون النص والحدود | لون النقطة (Dot) |
|---|---|---|---|---|
| `NEW` | جديد | `bg-rose-50` (`#FFF1F2`) | `text-rose-700 border-rose-200` | `#F43F5E` (Rose 500) |
| `IN_REVIEW` | قيد المراجعة | `bg-amber-50` (`#FFFBEB`) | `text-amber-800 border-amber-200` | `#F59E0B` (Amber 500) |
| `IN_PROGRESS` | جاري العمل | `bg-sky-50` (`#F0F9FF`) | `text-sky-800 border-sky-200` | `#0EA5E9` (Sky 500) |
| `RESOLVED` | تم الحل | `bg-emerald-50` (`#ECFDF5`) | `text-emerald-800 border-emerald-200` | `#10B981` (Emerald 500) |
| `REJECTED` | مرفوض | `bg-slate-100` (`#F1F5F9`) | `text-slate-700 border-slate-200` | `#64748B` (Slate 500) |

### 3.3 ألوان الخلفيات والأسطح (Surfaces & Neutrals)
* **خلفية التطبيق العامة (`bg-canvas`):** `#F8FAFC` (Slate 50) — مريحة للعين وتمنع إجهاد النظر طوال اليوم.
* **البطاقات والأسطح المرتفعة (`bg-surface`):** `#FFFFFF` الأبيض الصافي مع حدود متناهية الدقة `border-slate-200/80`.
* **النصوص الرئيسية:** `#0F172A` (Slate 900) — كحلي رمادي عميق بديل للأسود القاتم لسهولة القراءة.
* **النصوص الثانوية:** `#64748B` (Slate 500).

## 4. نظام الطباعة والخطوط (Typography System)

### 4.1 الخطوط المعتمدة
1. **الخط العربي الأساسي:** **Alexandria (الإسكندرية)** أو **Cairo (القاهرة)** عبر Google Fonts.
   * *السبب:* خطوط هندسية عصرية ذات تباعد مريح وأوزان متعددة، صُممت خصيصاً لتناسب شاشات العرض العربية وقراءة الأرقام العربية اللاتينية معاً دون تشوه.
2. **الخط اللاتيني والأكواد والأرقام:** **Plus Jakarta Sans** أو **Outfit**.
   * *السبب:* متناسقة تماماً مع هندسة خط Alexandria لعرض أكواد التتبع (`SBL-K7HN3R`) والأرقام الإحصائية بوضوح.

### 4.2 السلم الطباعي (Type Scale)

```css
/* Typography Scale */
--font-arabic: 'Alexandria', 'Cairo', system-ui, sans-serif;
--font-latin: 'Plus Jakarta Sans', system-ui, sans-serif;

/* Hierarchy */
h1.hero-title   { font-size: 2.25rem; font-weight: 700; line-height: 1.25; } /* 36px */
h2.page-header  { font-size: 1.50rem; font-weight: 700; line-height: 1.30; } /* 24px */
h3.card-title   { font-size: 1.125rem; font-weight: 600; line-height: 1.40; } /* 18px */
body.base-text  { font-size: 0.875rem; font-weight: 400; line-height: 1.50; } /* 14px */
small.caption   { font-size: 0.750rem; font-weight: 500; line-height: 1.40; } /* 12px */
code.tracking   { font-family: var(--font-latin); font-weight: 700; letter-spacing: 0.05em; }
```

## 5. لغة الواجهات (UI Design Language & Components)

### 5.1 النمط الجمالي: "Clean Civic High-Density"
* **الاتجاه الأصيل:** `dir="rtl"` من رأس الصفحة إلى أسفلها، مع مراعاة الهوامش البادئة والمنتهية (`ps-*` و `pe-*`).
* **انحناء الزوايا (Border Radius):**
  * البطاقات وكروت الـ KPIs: `rounded-2xl` (16px).
  * الأزرار والمدخلات: `rounded-xl` (12px).
  * البادجات وحبوب الحالات: `rounded-full` (9999px).
* **الظلال الدقيقة (Micro-Shadows):**
  * استخدام ظلال ناعمة للغاية ذات شفافية منخفضة (`box-shadow: 0 1px 3px 0 rgb(0 0 0 / 0.05)`).
* **الفصل بالحدود بدلاً من التباعد المفرط:** استخدام خطوط رفيعة 1px بلون `border-slate-200` لمنح واجهة الموظف كثافة بيانات عالية تتيح له رؤية 15 بلاغاً دون الحاجة للتمرير المستمر.

## 7. تطبيق الهوية على رسائل الواتساب (WhatsApp Branding)

لكي تنعكس الهوية في رسائل الواتساب اليومية:
1. **الترويسة الموحدة:** تبدأ كل محادثة برمز المنظومة:
   ```
   أهلاً بك في منصة واصل 🏙️
   خدمة البلاغات والمتابعة لـ [اسم المنظمة]
   ━━━━━━━━━━━━━━━━━━━━
   ```
2. **شكل بطاقة البلاغ المتناسق:**
   ```
   📋 حالة البلاغ: SBL-K7HN3R
   ━━━━━━━━━━━━━━━━━━━━
   🔧 النوع: إنارة عامة
   📊 الحالة: 🔵 جاري العمل
   📅 التاريخ: ١٠ أكتوبر ٢٠٢٦
   
   💬 آخر رد: "تم توجيه فني الكهرباء للموقع"
   ━━━━━━━━━━━━━━━━━━━━
   واصل.. صوتك واصل وبلاغك محلول ✨
   ```
